# GitHub 代码快照

来源：本机项目在 2026-10-10 整理的独立副本。上传过程不修改正在运行的服务、会话和原项目 Git 状态。

## 恢复范围

仓库提供应用源码、前端、测试、SQL 模板、指标和数据源合同，以及 `deployment/knowledge/` 中的已发布知识快照。

恢复命令：

```powershell
.\.venv\Scripts\python.exe scripts\restore_published_knowledge.py
```

脚本验证快照清单和文件哈希，将快照放入新安装的 `var/knowledge-releases/`，再原子设置活动指针。重复执行会复核一致性；已有不同活动版本时停止，避免意外回退。它不连接生产服务。

## 未上传的本机内容

- `.env`、`.env.bak` 和模型认证。
- 安装身份、会话库、审计内容、学习账本和 IP 申请/审批。
- Doris 业务结果、Excel/CSV/PDF/Word 导出及报表产物。
- 浏览器用户目录、截图、调试记录、临时文件。
- 历史现场验收记录和包含业务结果的参考文档。

因此，部分历史验收测试依赖的本机证据文件不在公开仓库中。随附 CI 只运行明确列出的离线测试，不宣称整个本机历史测试集已通过。

## 使用前配置

1. 安装依赖并恢复已发布知识。
2. 本机创建 `.env`，配置自己的 Doris 只读账号、网关和模型。
3. 新机器重新配置访问策略及 IP 审批。
4. 启动服务，核验真实查询和报告导出。

业务语义以恢复后的已发布快照为准，根目录可能保留候选合同。不能把历史文档或候选版本当成已批准的新口径。
